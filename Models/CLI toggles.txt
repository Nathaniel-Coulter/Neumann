Toggles via CLI flags (no YAML needed):

--models logistic mlp lgbm (or --models all)

--calibration none|platt|isotonic

--kfold 1|5|... (used for logistic; MLP/LGBM use a simple train/val split—keeps runtime sane)

--horizons 12 24 36

--train_months 60 (rolling window) and --test_step 1

--topn 10 (for long/short baskets)

--no-download (if you’ve already cached monthly prices as monthly_prices.parquet)

3) Add calibration (compare Platt vs Isotonic)

Purpose: better-calibrated probabilities (your P(up) is more “truthy”).

# Isotonic
python .\project\ml_refine.py --models logistic --horizons 12 --kfold 5 --calibration isotonic

Pro tips

After the first run builds monthly_prices.parquet, you can add --no-download to make later runs faster:

python .\project\ml_refine.py --models logistic --horizons 12 --kfold 5 --calibration isotonic --no-download


Compare models/horizons by grouping in oos_summary.csv (AUC, long_hit, short_hit). Your negative basket (“short”) is already logged each month in predictions_rolling.csv via short_names.

If you want an ultra-quick check on just 12m horizon with everything on:

python .\project\ml_refine.py --models all --horizons 12 --kfold 5 --calibration isotonic
